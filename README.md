# Esp32-wifi-atack-capture
Es una herramienta que sirve para **cualquier ESP32** 
hasta el mas basico como el mio que es el **(ESP32 WROOM 32)**

Fue basada en el proyecto original de **RISINEK** **(https://github.com/risinek)** [Gracias por crear esta herramienta loco :)]

El único cambio fue el **estilo de la interfaz web** para que se vea como una **aplicacion.** 
ahora es **mas comoda** y **linda** a la vista. (se tuvo que cambiar lineas en los Cmakelist.txt para poder compilarse)
