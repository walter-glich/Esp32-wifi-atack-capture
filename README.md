[GESTION DE ESP32]

> [**INTERFAZ INALAMBRICA PARA EL ESP32**]
>  Una interfaz web local para configurar y poner en marcha operaciones del ESP32 desde un navegador.
----------------------------------------------------------------------------------------- 
**[INTERFAZ]**

El proyecto ofrece un panel de gestión sencillo y adaptado a dispositivos móviles al que se puede acceder desde la red local del ESP32.

[CARACTERISTICAS]

-  **[Gestión inalámbrica]** a través de una interfaz web local
-  **[Selección de destino]** entre las redes disponibles
-  **[Configuración de operaciones]** desde el navegador
-  **[Actualización de redes]** directamente desde la interfaz
-  **[Tiempo de espera configurable]** para las operaciones
-  **[Inicio de la operación]** con una sola acción
-  **[Interfaz intuitiva]** diseñada para usarse cómodamente desde un teléfono
